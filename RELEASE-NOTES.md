Moblift **0.16.3** adds a small Mobbin icon to the Mac menu bar. This release is **Developer ID-signed and notarized by Apple**.

**[Download Moblift for Mac](https://github.com/crnelious/Moblift-downloads/releases/latest/download/Moblift-macOS.zip)**

## What's new

- A subtle, monochrome Mobbin mark in the menu bar, with **Open Moblift** and **Quit Moblift**.
- Open brings the workspace forward, restores it when minimized, or reopens it after closing the window.
- Hide or show the icon in **Settings → General → Show Moblift in the menu bar**. It is enabled by default and appears while the app is running.

## Install or update

1. Quit your existing copy of Moblift.
2. Download **Moblift-macOS.zip**, unzip it, and move **Moblift.app** to **Applications**, replacing the previous version if prompted.
3. Open Moblift and confirm macOS's normal first-open prompt if shown.

Requires an **Apple Silicon Mac (M1 or newer)** running **macOS 14 or later**. Intel Macs and Windows are not supported by this build. Built and checked on macOS 27 using Xcode 27; compatibility has not been tested on every macOS version declared by the app.

This is **version 0.16.3, build 28**, with Apple's notarization ticket included. Automatic updates are not included.

Ordinary capture and video import do not require Xcode. Optional experimental iPhone remote control still requires Xcode, iPhone Developer Mode, and an Apple development team. See the attached **Moblift-Quick-Start.md**.

The main app source repository remains private. The download includes its runtime dependencies and the two Moblift helper source files needed for optional remote control. No capture library is included.
